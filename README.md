## How to Run
Built with Processing.
Processing version: 4.0.1

The project folder is called calculator and the main .pde is called calculator.pde.

## Controls
Mouse:
Click on the number buttons to put them in the display. Click the operator buttons to perform the operation. Click = to calculate.

Keyboard:
Pressing any number key will type their respective number. Pressing any +,-,/ or x will do the corresponding operation. Press enter to calculate.
